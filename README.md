# My Timetable (web)

Installable web app version of My Timetable: class timetable, tasks, exams, CGPA, holidays calendar, themes.
Works offline. Everything a person enters stays on their own phone (localStorage); nothing is uploaded.

Install on iPhone: open the site in Safari → Share → Add to Home Screen.

Screenshot/photo timetable and results import runs on the phone with Tesseract.js (Apache-2.0, `ocr/`);
QR codes use jsQR (Apache-2.0).
